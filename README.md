# test_cruft

A short description of the project

## Auteur

Antoaneta Stoyanova

## Prérequis

- Python >= 3.13
- [uv](https://docs.astral.sh/uv/)
- [cruft](https://cruft.github.io/cruft/) — pour mettre à jour le template

## Installation

```bash
git clone https://github.com//test_cruft.git
cd test_cruft
uv sync
```

## Utilisation

```bash
uv run python -m test_cruft
```

## Mettre à jour depuis le template

```bash
cruft update
```
